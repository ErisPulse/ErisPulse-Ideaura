## Overview

An adapter for the Ideaura (花枫咖啡馆 / RockyChat) platform, built on the [ErisPulse](https://github.com/ErisPulse/ErisPulse/) architecture, exposing all platform features through a unified event and messaging interface.

Fully compatible with OneBot12 standard events, plus platform extension events (message edit/recall/forward/read, friend online/offline, user status change…) — see the event mapping table in the Chinese README below.

## Install

```bash
epsdk install Ideaura
```
